# 文本资源整合 Web 项目开发文档

## 项目简介

该项目基于此前两次任务中提交的文本文件，构建了一个开箱即用的 Express Web 应用：

- 后端提供统一的 `/api` 接口，用于读取 `data/` 目录中的文本文件。
- 前端使用原生 HTML/CSS/JavaScript，展示可用文本列表并支持在线预览。
- 内置健康检查、错误处理和前端静态资源服务。

项目适用于快速演示如何将已有的文本资源整合到一个可运行的 Web 服务中，同时为后续扩展提供清晰的目录结构和开发流程。

## 系统要求

- Node.js >= 18
- npm >= 9（Node.js 自带）
- 推荐在 macOS、Linux 或 Windows 10+ 环境中开发与部署。

> 使用 `node -v` 和 `npm -v` 可快速确认当前环境版本。

## 快速开始

1. **安装依赖**

   ```bash
   npm install
   ```

2. **开发模式运行**（带文件变更监听）

   ```bash
   npm run dev
   ```

   默认监听 <http://localhost:3000>。

3. **生产模式运行**

   ```bash
   npm start
   ```

   若需要自定义端口，可在启动命令前设置 `PORT` 环境变量：

   ```bash
   PORT=4000 npm start
   ```

4. **访问项目**

   打开浏览器访问 <http://localhost:3000> 即可看到整合后的前端界面。

## 目录结构

```
.
├── data/                  # 前两次任务的文本文件资源
├── docs/                  # 项目文档（Markdown 版本）
├── public/                # 静态资源目录，包含前端页面与开发文档 HTML 版本
│   ├── docs/
│   │   └── 开发文档.html
│   ├── index.html
│   └── styles.css
├── src/                   # Express 服务端源码
│   ├── index.js           # 应用入口，注册中间件与路由
│   ├── routes/api.js      # API 路由定义
│   └── services/textService.js
├── package.json
└── package-lock.json (首次执行 `npm install` 后自动生成)
```

## 运行机制说明

- `src/index.js` 中创建 Express 应用，加载日志中间件、JSON 解析中间件以及静态资源服务。
- `/api` 路径下由 `routes/api.js` 提供接口，当前包含：
  - `GET /api/health`：健康检查。
  - `GET /api/texts`：读取 `data/` 目录下所有 `.txt` 文件并返回内容。
  - `GET /api/texts/:name`：按文件名（不含 `.txt` 后缀）返回单个文本内容。
- 其余 GET 请求均回退到 `public/index.html`，用于前端路由或直接展示页面。

## 数据源管理

- 所有文本文件统一放置在 `data/` 目录。
- 新增文本时仅需将 `.txt` 文件置入该目录，无需改动源码，接口会自动收集。
- 如需支持其他类型文件，可扩展 `services/textService.js` 中的文件过滤逻辑。

## 前端说明

- `public/index.html` 为主页面，使用原生 ES Module 编写的脚本请求 `/api` 接口。
- `styles.css` 提供基础样式和响应式布局。
- 页脚提供文档入口，链接到 `public/docs/开发文档.html` 以便部署后直接查看。

## 部署建议

1. **安装依赖**（仅需一次）：`npm install`
2. **构建流程**：本项目为服务端渲染 + 静态资源，无需额外构建步骤。
3. **生产启动**：`npm start`
4. **进程守护**：推荐搭配 `pm2`、`systemd` 或容器方式运行，以保证高可用。

## 常见问题

| 问题 | 解决方案 |
| ---- | -------- |
| 启动报错 `EADDRINUSE` | 检查端口是否被占用，修改 `PORT` 或释放端口。 |
| 浏览器无法加载文本列表 | 查看后端日志，确认 `data/` 目录是否存在 `.txt` 文件以及文件权限。 |
| 页面样式错乱 | 确保 `/public/styles.css` 能被正常访问，或检查浏览器缓存。 |
