# 文本资源整合 Web 项目

将前两次任务中的文本文件整合为一个可直接运行的 Express Web 应用。后端提供文本数据接口，前端负责展示与预览，实现“开箱即用”的体验。

## 功能概览

- `/api/texts` 接口自动收集 `data/` 目录中的所有 `.txt` 文件。
- 前端页面列出所有文本资源，并支持逐行预览。
- 内置中文开发文档，既提供 Markdown 版本也提供 HTML 版本，方便部署后直接查看。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式运行（含热重载）
# 或
npm start          # 生产模式启动
```

应用默认监听 <http://localhost:3000>，启动后即可通过浏览器访问。

如需了解更多细节（目录结构、接口说明、部署建议等），请阅读 `docs/开发文档.md` 或访问运行中的 `/docs/开发文档.html` 页面。
